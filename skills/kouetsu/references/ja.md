# Japanese patterns

Not a banned-word list. Fix these when they repeat, and only after fixing the cause (content and clarity).

- **Nominalization with 「〜を行う」**: 「検証の実施を行いました」→「検証しました」. Rewrite chains like 「〜における〜の〜」 with a subject and a verb.
- **「〜することができます」**: if it is a fact, write 「〜します」 or 「〜できます」.
- **Hedged endings**: 「〜と言えるでしょう」「〜と考えられます」「〜かもしれません」 → assert if sure; otherwise say what is uncertain.
- **Empty modifiers**: 「さまざまな」「多岐にわたる」「効果的な」「重要な役割を果たす」 → be specific, or delete.
- **Signposting**: 「〜について見ていきましょう」「まとめると」「結論として」「いかがでしたか」 → delete.
- **Negative parallelism**: repeated 「単なるXではなく、Yです」「XだけでなくYも」 → state Y.
- **Runs of 体言止め**: even in bullet lists, write full sentences when the relations between items disappear.
- **Stacked keigo**: repeated 「〜させていただきます」 → once is enough.
- **「〜になります」 for something that simply is**: 「要件定義書になります」→「要件定義書です」.
- **Katakana inflation**: do not rename plain things with grand loanwords.
