# Korean patterns

Not a banned-word list. Fix these when they repeat, and only after fixing the cause (content and clarity).

- **Translationese nominalization**: "~에 대한 ~의 수행", "~를 통해 ~가 이루어진다", "~함으로써" → rewrite with a subject and a verb. "분석을 진행했다" → "분석했다"
- **Overused "~할 수 있습니다"**: if it is a fact and not a possibility, write "~합니다".
- **Hedged endings**: "~라고 할 수 있습니다", "~것으로 보입니다" → assert if sure; otherwise say what is uncertain.
- **Empty modifiers**: "다양한", "효과적인", "체계적인", "혁신적인", "핵심적인" → say what and how, or delete.
- **Signposting**: "~에 대해 살펴보겠습니다", "정리하면 다음과 같습니다", "결론적으로" → delete and go straight to the content.
- **Negative parallelism**: "단순한 X가 아니라 Y입니다", "X를 넘어 Y로" → state Y.
- **Overused noun-ending report style**: lines cut off with "~함", "~임" lose the actor and the relations between items. If the reader lacks context, write full sentences.
- **Particle chains**: "~의 ~의 ~" → unpack.
