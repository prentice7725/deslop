# Korean patterns

Not a banned-word list. Fix these when they repeat, and only after fixing the cause (content and clarity).

- **Translationese nominalization**: "~에 대한 ~의 수행", "~를 통해 ~가 이루어진다", "~함으로써" → rewrite with a subject and a verb. "분석을 진행했다" → "분석했다".
- **Double passives**: "~되어지다", "~보여지다", "~불려지다" → single passive or active ("~되다", "~보이다").
- **Compulsive pronouns and repeated subjects**: "그/그녀", or repeating the same subject or "그것은" in consecutive sentences → omit when the actor is already clear from the previous sentence; if "그것은" points to something ambiguous, replace it with the actual noun instead. Name the actor again only when it changes or responsibility would otherwise blur.
- **Overused "~할 수 있습니다"**: if it is an already verified fact rather than a possibility or unverified proposal, state it directly in the document's register (e.g., "~합니다", "~해요").
- **Hedged endings**: "~라고 할 수 있습니다", "~것으로 보입니다" → assert if sure; otherwise say what is uncertain.
- **Formal noun and obligation padding**: "~하는 것이다", "~라는 점", "~할 필요가 있다" → state the action directly ("검토할 필요가 있습니다" → "검토해야 합니다" or "검토합니다").
- **Empty modifiers**: "다양한", "효과적인", "체계적인", "혁신적인", "핵심적인" → say what and how, or delete.
- **Translated metaphors**: "~라는 렌즈로 보면", "~개의 축으로 정리된다", "~라는 토대 위에서" → name the actual criterion, grouping, or condition, or delete if the source states none.
- **Signposting**: "~에 대해 살펴보겠습니다", "정리하면 다음과 같습니다", "결론적으로" → delete and go straight to the content.
- **Sentence-initial connector chains**: "또한", "따라서", "즉", "나아가" opening consecutive sentences → let sentence order carry the logic, or merge.
- **Negative parallelism**: "단순한 X가 아니라 Y입니다", "X를 넘어 Y로" → state Y.
- **Commas after connective endings**: "~하며,", "~하고,", "~인데," in every clause → drop commas that only mimic English pause rhythm; keep them only to prevent misreading in long clauses.
- **Redundant English parentheticals (with loanword guard)**: "성능(Performance)", "확장성(Scalability)" → keep English only for actual identifiers, APIs, or terms readers search in English. Keep everyday technical loanwords ("파이프라인", "리뷰", "컴포넌트", "디플로이") rather than replacing them with stiff Sino-Korean words.
- **Overused noun-ending report style**: lines cut off with "~함", "~임" lose the actor and the relations between items. If the reader lacks context, write full sentences.
- **Particle chains and double particles**: "~의 ~의 ~", "~에로의", "~으로부터의", or stacked "~에서의 ~의" → unpack with a verb.
- **Register drift**: do not mix "~합니다", "~해요", and "~이다" in one document, and preserve the author's register during revision.
